# Pi Popchat 一期交付与验收报告

交付日期：2026-09-09。范围：macOS 桌面客户端，Go + Wails v3 + React，第一期接入用户自行安装配置的 Pi。需求中列出的功能均已有实现；以下区分自动化、真实模型、真实桌面与未观测的操作系统边界，不将模拟测试等同于全部端到端通过。

## 可运行交付

运行 `sh scripts/run-app.sh`，或打开 `dist/Pi Popchat.app`。默认 `⌥Space` 呼出浮窗，原生“窗口”菜单和菜单栏图标也能打开界面。关闭窗口保持任务运行，主动退出才结束本应用启动的 Pi 进程。应用不需要终端常驻。

本次构建在 Apple Silicon、macOS 15.6.1 完成，声明最低 macOS 15，未测试其他系统小版本或 Intel。应用已作本机 ad-hoc 签名并校验；未使用开发者证书签名或 Apple 公证，因此交付的是本机可运行版本，不是已验收的公开分发安装包。

应用不直接连接模型、不读取或管理模型凭证、不安装 Pi、不扫描终端会话。Pi 0.84.1 为已验证协议基线。语音、文件编辑器、其他 Agent 适配均不在一期范围。

## 架构落地

| 模块 | 职责与实现 |
|---|---|
| Agent 边界 | `internal/agent` 定义客户端与工厂；`internal/agent/pi` 封装 JSONL RPC、请求匹配、能力发现及所属进程组生命周期 |
| 会话与恢复 | `internal/core` 管理两窗选择、一个会话一个运行时、投递意图、队列、交互及崩溃恢复；SQLite 保存应用索引，Pi 原生日志保持上下文；适配层逐条只读提取展示文字，避免多轮图片历史挤入单条 RPC |
| 桌面 | AppKit NSPanel、活动窗口选屏、全局快捷键、文件/目录系统操作、通知与退出；所有窗口可见性变更在主线程串行执行 |
| 前端 | React 共享快照，稳定提交 ID 与草稿版本，异步操作绑定原会话；生成的 Wails 类型绑定连接桌面服务 |

不创建额外守护进程、模型网关或通用插件框架。后台闲置进程可回收，历史继续时按登记的 Pi 会话恢复。客户端队列在停止、失败、崩溃重启后暂停，未知投递结果不自动重发。

## 修复闭环与验证边界

独立验收发现并修复了：跨会话异步串发、附件移除后复活、同模型 ID 跨 Provider 误选、投递持久化失败、启动与删除竞争、UI-only 命令导致历史错配、停止后延迟重试/交互、投递收尾与 settled 交错造成队列停滞、退出后回调访问存储，以及 Wails 首次导航晚到 Show 导致窗口重新出现。原生探针必须等待实际导航和全屏事件，并严格检查 JSON 结果，不能仅凭进程退出码成功。

全屏验证使用本应用的真实主窗口和 NSPanel，证明 Space 转换后的可见性与键盘焦点，不等同于所有第三方全屏应用的像素遮挡验证。中文内容显示和输入已验证，输入法事件测试已通过，但未物理操作拼音候选框。没有实测整夜休眠、长时间断网、所有外部快捷键冲突或完整 VoiceOver 流程，不宣称这些组合均已通过。
