# Pi Popchat v0.1.0

首个公开版本：让本机 Pi 成为随时可以唤起的桌面对话助手。

## 可以做什么

- 按 ⌥Space 在当前活动窗口所在显示器唤起浮窗，支持其他应用的全屏空间；Esc 收起，任务继续。
- 在主窗口搜索、置顶、重命名、删除或继续历史会话。
- 粘贴图片、拖入文件，选择 Pi 提供的模型，使用 `/` 命令；模型列表复用缓存，可手动刷新。
- 执行中继续补充消息，默认排队，也可立即插入；支持停止与中断后的主动恢复。
- 选择工作目录、用系统默认应用打开文件、接收任务通知。

## 下载与使用

下载 `Pi-Popchat-v0.1.0-macOS-arm64.zip`，解压后将 `Pi Popchat.app` 放入“应用程序”。需先自行安装并配置 Pi，再打开应用；兼容验证基线为 Pi 0.84.1。

仅提供 macOS 15 / Apple Silicon 构建。应用使用 ad-hoc 签名，尚未使用 Developer ID 签名或通过 Apple 公证，macOS 可能阻止直接打开。源码与构建步骤见仓库 README。

`SHA256SUMS.txt` 提供安装包校验值，下载后可在文件所在目录执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

## 当前边界

目前仅接入 Pi；Codex、Claude Code 和语音功能尚未提供。模型及登录配置由 Pi 管理；本地保存历史不意味着模型请求离线处理。Intel Mac 与其他 macOS 版本未验证。

## 验证与许可证

发布前依赖校验、28 项前端检查、Go 核心/适配器/桌面竞态检查及生产构建通过。多屏全屏、图片粘贴等原生验证范围及失败记录保留在 `docs/reviews` 和 `docs/validation`，不宣称覆盖所有桌面环境。
