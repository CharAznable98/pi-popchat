# Pi Popchat v0.1.1

快捷键唤起浮窗现在跟随鼠标所在的显示器。

- 按 ⌥Space，在鼠标所在屏幕的可用区域居中打开浮窗，并聚焦输入框。
- 浮窗已经显示时：鼠标在同屏，再按快捷键收起；鼠标在另一屏，则把浮窗移过去。
- 唤起后移动鼠标不会移动浮窗；隐藏浮窗不会停止 Agent 任务。

状态栏图标菜单继续只提供打开主窗口和退出；应用顶部“窗口 → 打开浮窗”仍按活动窗口选屏。

## 下载与升级

退出旧版，下载 `Pi-Popchat-v0.1.1-macOS-arm64.zip`，解压后替换“应用程序”中的 Pi Popchat.app。现有本地会话数据继续保留。

支持范围仍为 macOS 15 / Apple Silicon。应用使用 ad-hoc 签名，未通过 Apple 公证；Intel Mac 和其他 macOS 版本未验证。使用前需安装并配置 Pi。

下载目录中执行 `shasum -a 256 -c SHA256SUMS.txt` 可校验安装包。

## 验证

28 项前端检查、Go race 检查、生产构建与签名校验通过。三屏原生验收复测 64/64 通过，覆盖鼠标选屏、居中、跨屏切换、输入和全屏。首轮两项焦点不稳定的失败记录仍保留，详见仓库 `docs/reviews/mouse-screen-placement.md`；本轮未重新验证物理快捷键的系统投递。
