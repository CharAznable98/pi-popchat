# Pi Popchat v0.1.2

新会话在首次提交消息后才进入历史，减少空会话。

- 点击新会话或超时自动切换时，先使用全应用共享草稿；浮窗和主窗口共用同一份草稿。
- 首条消息成功保存后，草稿转为正式会话；保存失败保留草稿，Agent 执行失败保留已提交的会话。
- 删除使用应用默认工作目录的会话时，可选择同时删除目录；默认保留目录，自选目录和来源不明的旧目录不会自动删除。
- 补强共享目录、目录被替换、并发删除及 Agent 关闭失败的处理。已有空会话仍由用户手动整理。

## 下载与升级

退出旧版，下载 `Pi-Popchat-v0.1.2-macOS-arm64.zip`，解压后替换原应用。现有本地会话数据保留。

支持 macOS 15 / Apple Silicon，使用 ad-hoc 签名，未通过 Apple 公证。Intel Mac 和其他 macOS 版本未验证；使用前需安装并配置 Pi。

下载目录中执行 `shasum -a 256 -c SHA256SUMS.txt` 可校验安装包。
