## 已闭环缺陷

| 严重性 | 触发及原结果 | 修复后独立断言 |
|---|---|---|
| P1 | A 草稿保存尚未返回时点击发送，外部快照切到 B，A 保存返回后将 B 文字发给 A | 发送内容及会话 ID 在等待前绑定，不能将 B 文字交给 A |
| P1 | 从草稿移除已有附件只更新界面，未更新引用或持久化，刷新后附件可复活 | 移除后对原会话保存空附件列表 |
| P1 | 附件上传期间切换会话，完成后仅放在本地缓存，原已保存文字可能被空值替换 | 完成后向原会话保存原文字与新附件，返回原会话保留文字 |
| P2 | 两个 Provider 暴露同一个模型 ID，选择第二项实际切换第一个 Provider | 使用 Provider 与 ID 复合选项，正确交付第二个 Provider |

## 仍需保留的审阅意见

1. `desktop.Action` 中 stop、queue、model 等动作最初使用窗口当前会话；实现者已统一传递明确的 `sessionId`，后端优先使用它。本组新增队列插入携带会话及消息 ID 的断言，并更新本地文件打开断言验证会话 ID。
2. 基础可访问性有输入 aria-label、消息 aria-live、状态与按钮语义；设置弹窗未见完整焦点圈定，Slash 的 listbox 未见方向键活动项管理。Tab 与鼠标入口仍可用，不将此描述为完整 VoiceOver 验证。
3. 默认 `npm test` 已纳入全部 React 测试；最终运行包含 4 项纯逻辑与 16 项 React 行为测试，全部通过。

以上意见已同步主实现者，不扩大到凭证管理、Agent 自研或文件编辑器等明确不在一期范围的能力。
