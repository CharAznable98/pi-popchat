# 模型目录更新策略

窗口可见性与元数据刷新分离：启动、新建、选择会话及浮窗打开调用 Prepare，已连接时复用会话模型目录且不发送查询、不产生新的加载状态。首次连接及因空闲回收后的重新连接会读取 Agent 元数据。保留 Refresh 作为显式强制查询，设置中的“重新检测”继续调用它；外部 Pi 配置变化后使用此入口更新。

缓存按会话及 Agent 连接使用，不跨不同会话/工作目录混用，不增加轮询或文件监听，也不读取模型凭证。

回归 TestPrepareReusesModelsUntilExplicitRefreshOrReconnect 验证：20 个并发打开请求仅查询一次模型；继续打开不产生元数据版本变化；手动刷新恰好多一次查询且不重启进程；空闲回收后重新连接查询一次。sh scripts/test.sh 全部通过，含 28 项前端测试和 Go 竞态检查。生产构建通过。
